# Installation

## Stable release

To install forgeserve, run this command in your terminal:

```sh
uv add forgeserve
```

Or if you prefer to use `pip`:

```sh
pip install forgeserve
```

## From source

The source files for forgeserve can be downloaded from the [Github repo](https://github.com/danishshaikh06/forgeserve).

You can either clone the public repository:

```sh
git clone https://github.com/danishshaikh06/forgeserve
```

Or download the [tarball](https://github.com/danishshaikh06/forgeserve/tarball/main):

```sh
curl -OJL https://github.com/danishshaikh06/forgeserve/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd forgeserve
uv sync
```
